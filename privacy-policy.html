Privacy Policy

Last Updated: April 14, 2025

This Privacy Policy explains how this Discord bot (hereinafter referred to as "the bot") collects, uses, and protects user data.

1. Information Collected

  • User’s Discord ID
  • Time of joining or leaving the server
  • Information about roles given or removed
  • Log records generated by the use of bot commands

Note: This bot does not collect or store any personal information such as IP addresses, emails, or location data.

2. Use of Data

The collected data is used solely for the following purposes:

  • Providing moderation and role management functionality within the server
  • Managing restart/maintenance/announcement systems
  • Ensuring proper operation of automated systems
  • Archiving server logs (if a log channel is configured)

3. Sharing with Third Parties

User data is not shared with, sold to, or rented to any third parties.

4. Data Retention

Data is stored only as long as necessary and may be deleted by the server owner. If the bot is removed from the server, the data becomes inactive automatically.

5. User Rights

Users may request the deletion of their data by contacting the server administrators.
